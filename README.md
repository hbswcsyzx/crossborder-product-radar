# DaiVernon Research Tools

This repository is a public information page for DaiVernon Research Tools.

The actual source code of the internal research tool is private, local-first, and not hosted in this repository.

## Project Overview

DaiVernon Research Tools is developing an internal product and keyword research tool for cross-border e-commerce research.

The tool is intended to help evaluate product-related keyword demand, marketplace supply, sourcing cost estimates, and manual validation results.

It is used for internal research only.

## Google Ads API Usage

If Google Ads API access is enabled, it is used only for Keyword Planning Services, including:

* Keyword ideas
* Historical keyword metrics
* Average monthly searches
* Competition level
* Bid range estimates

The tool does not create, modify, or manage Google Ads campaigns.

It does not manage bids, budgets, ads, ad groups, conversion tracking, remarketing audiences, or Google Ads accounts.

## Intended Users

This tool is for internal use only by the project owner and direct technical assistants or contractors working under the owner's supervision.

It is not a public SaaS product and is not provided to external clients or advertisers.

## What the Tool Does Not Do

This tool does not:

* Create or manage Google Ads campaigns
* Automate ad buying or bidding
* Create marketplace listings
* Place orders
* Process payments
* Scrape logged-in Seller Hub or Terapeak pages
* Bypass platform access controls
* Guarantee business results
